# Support

HeiGate is community-maintained software provided without warranty.

Use GitHub Issues for reproducible defects and scoped feature requests. Before
opening an issue:

- read the relevant README and deployment documentation;
- search existing issues;
- test with the latest release or default branch when practical;
- remove secrets and personal or production data from logs and screenshots.

General deployment consulting, upstream account recovery, provider billing
disputes, bypassing provider restrictions, and emergency production support
are outside the project's support commitment.

Security vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md).
