范围：渠道内顺序轮询、独立凭证故障、429 冷却、Hermes Auto 容错。
不增加 Codex/Claude 接入、指纹伪装或 WebSocket。

## 冷却约定

429：5、10、20、30 分钟递增，30 分钟封顶；Retry-After 更长时遵守上游。
冷却期间不得兜底选择，到期只允许一个恢复请求，成功清零。
整个请求最多三次上游尝试，同渠道最多两把 Key。输出后不得重放。

## 迁移与回滚

旧渠道一对一生成 Key，保留渠道 ID 和原 api_key 兼容字段。
多 Key 渠道不允许旧接口直接修改密钥，必须使用 Key 管理。
数据库首次迁移前使用 VACUUM INTO 在数据库同目录创建 pre-key-pool 时间戳备份。
回滚需停止应用并恢复该备份；升级后的新数据须另行保留。
同地址渠道不自动合并；源渠道合并后默认仅禁用，历史日志不重写。
